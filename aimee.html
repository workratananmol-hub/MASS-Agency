MASS product 02 / Education · In development

AIMEE.

A retrieval teaching agent MASS is building for teachers. It answers from a private educational corpus—not the open web—and a teacher still reviews the draft.

Status

Prototype in development. Not a public classroom product.

Corpus

Private set of 700+ educational PDFs assembled for this product.

Available now

Retrieval drafts with source citations, for teacher review.

Not available

Telegram interface, student-facing chat, unreviewed send.

What AIMEE is

700+ PDFs. One retrieval partner.

MASS has assembled a private educational corpus of more than 700 PDFs for AIMEE. The agent retrieves from that corpus. It does not browse the open web, and it is not a substitute for a teacher.

01

Source access

Only files MASS has placed in the AIMEE corpus. No student records, no unrelated drives, no live internet search.

02

Retrieval

A question pulls matching passages. The draft is supposed to cite those passages. If nothing relevant is found, the honest output is a refusal—not a fabricated lesson.

03

Teacher review

Notes, worksheets, and question sets are drafts. A teacher edits, accepts, or rejects before anything reaches a class.

Limits and privacy

What AIMEE will not do.

Limitations

  • It can miss a better passage in the corpus or quote a source out of context.
  • It cannot verify that a worksheet is grade-accurate without the teacher.
  • Memory of preferences is a planned aid for repeat work, not a student profile system.

Privacy

AIMEE is not built to ingest a school’s live student data. Prompts and drafts in the prototype stay inside the MASS development environment. A school deployment would need a separate data agreement; that is not the current product.

Do not paste identifiable student work into AIMEE. The corpus is instructional PDFs, not a classroom archive.

Sample output

The shape of a grounded draft.

The block below is a demonstration of format—how a retrieval reply is structured—not a live session log exported from production AIMEE. Genuine classroom use still requires a teacher to check the source and the task.

Teacher request

Starter activity, grade 8

“Draft a 20-minute starter on photosynthesis. Use only our uploaded notes. Cite the page.”

Retrieved source

Energy in ecosystems, p. 12

“Plants convert light energy into chemical energy stored in glucose.” AIMEE is supposed to quote a passage like this, not invent a textbook.

Draft output

What the teacher sees

  • 5-minute recall prompt on light vs chemical energy
  • 10-minute labeled diagram of a leaf
  • 5-minute exit ticket: one sentence, one citation
Review

Human checkpoint

The teacher keeps, edits, or discards the draft. AIMEE does not send materials to students in the current build.

Built now

Retrieval drafts from the corpus.

  • Question → matching passages from the 700+ PDF set
  • Cited draft of notes, worksheets, or question sets
  • Teacher review before classroom use
Planned — not live

Telegram is not available.

A Telegram interface is on the roadmap so teachers can request drafts in a familiar chat. It is not shipped. There is no AIMEE bot to add today, and no student-facing chat.

A teaching prototype, not a school platform.

AIMEE is a MASS education product in development. If you need a custom retrieval agent for your own documents, that is client work on the Agentic AI service—not a download of AIMEE.
