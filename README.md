# MASS Agency website

Static production source for https://mass.llc on branch `seo/deploy-ready`.

- `npm ci` installs the local preview dependency.
- `npm run seo:audit` checks metadata, canonicals, sitemap coverage, local references, fragments, indexable-page discovery and shipped JavaScript syntax.
- `npm run package:release` creates the Hostinger archive in the registered site's `output/` directory. Python 3 is required for ZIP creation and integrity checks.

See [SEO_DEPLOYMENT.md](SEO_DEPLOYMENT.md) for upload instructions, canonical redirects and post-upload verification. Upload the production ZIP contents directly into `public_html`, preserving `.htaccess` and `.well-known`.

MIMS is in development and replaces AIMEE at `/mims`. The initial release is CBSE Classes 9–10 mathematics taught in English, including Class 10 Basic and Standard. Other subject examples illustrate future vision. `/campus` covers AI seminars and masterclasses.

Contact, Campus and MIMS forms prepare email requests with copyable fallback text. They do not submit to a lead database or confirm that a message has been sent. Optional Google Analytics loads only after a visitor opts in using Privacy settings.
