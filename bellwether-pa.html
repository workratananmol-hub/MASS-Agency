MASS product 01 / Flagship · In development

Bellwether PA.

MASS’s operations product. It is being built as reusable software—not sold today as a login. The first workflows are the same jobs MASS already scopes in custom agent work.

Product stage

In development. No public dashboard. No self-serve plan.

First workflows

Support triage, lead qualification, internal retrieval.

Approvals

A person still sends customer-facing and CRM-write actions.

How to start

A custom agent pilot on Agentic AI—not a Bellwether login.

What is concrete now

Three workflows. One approval rule.

Bellwether PA is the productization of work MASS already does for clients. Until it ships as software you can subscribe to, the honest way to use this capability is a scoped pilot.

01

Support triage

Read a ticket, retrieve approved policy, draft a reply or a route. A specialist accepts, edits, or rejects before the customer sees it.

02

Lead qualification

Turn an inbound enquiry into a structured brief and a proposed CRM update. Writes wait on approval.

03

Internal retrieval

Answer from named playbooks and files. If the source is missing, the output is a refusal—not a guess.

Integrations and control

Tools you already run. Rights you can name.

Supported in the first design

Helpdesk or inbox, CRM, and a file or knowledge store—the same classes MASS uses in custom agent work. Specific vendors are chosen per deployment. There is no public connector marketplace and no claim that every SaaS tool is already wired.

Approvals

Read, draft, and write are separate. Customer messages and record changes stay behind a human checkpoint in the first release. Tool calls are logged. This matches the guardrails on the Agentic AI service page—because Bellwether is meant to encode that practice, not skip it.

Demonstration

What we can show today.

The working demonstration is the custom-agent path: one workflow, tight permissions, a review queue. That is live as client work. It is not yet a multi-tenant Bellwether product you can sign into.

Roadmap — labeled as such

Not shipped.

  • Self-serve workspace and billing
  • A published list of one-click integrations
  • Unattended send to customers
  • A marketplace of community workflows

Flagship means priority, not “available.”

If you need operations automation this year, start a custom agent engagement. If you want to follow Bellwether as a product, say so in the brief—we will not pretend a login exists.
